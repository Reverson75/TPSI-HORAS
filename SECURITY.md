# Segurança

## Dados
Todos os dados (horas, avaliações, notas) ficam guardados apenas no telemóvel, numa base de dados SQLite na pasta privada da app. Não existe servidor nem conta de utilizador, e a versão de Release não pede permissão de internet.

## Permissões Android
- Notificações: para os lembretes de testes e avaliações.
- Alarmes exatos: para o lembrete disparar à hora certa.
- Arranque do dispositivo: para repor os lembretes após reiniciar.

## Instalar o APK
O APK é assinado. Antes de instalar, confirma o hash SHA-256 indicado na página da release.
